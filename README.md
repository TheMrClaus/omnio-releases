# Omnio TV releases

Signed Android builds of **Omnio TV** for Android TV, Fire TV and Android phones (Android 7.0 or newer).

Download the latest `.apk` from [Releases](https://github.com/TheMrClaus/omnio-releases/releases/latest).
More about the app: [omnio.tv](https://omnio.tv). Privacy policy: [omnio.tv/privacy](https://omnio.tv/privacy).
